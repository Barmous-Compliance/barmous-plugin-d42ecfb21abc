# Perplexity remote connector fields

- Type: Remote
- Transport: Streamable HTTP
- Authentication: OAuth
- MCP server URL: use only the verified HTTPS endpoint published by Barmous
- Icon: `assets/barmous-connector.png` (PNG, under Perplexity's 128 KB limit)
