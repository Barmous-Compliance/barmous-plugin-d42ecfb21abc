# Barmous Compliance plugin preview distribution notice

These packages are evaluation previews of the Barmous Compliance read-only CLI and local MCP integrations for Codex and Claude Code. They are provided for testing by recipients who have an authorized Barmous account.

No credential is included. `barmous login` uses browser approval to issue a company-scoped credential with a `1h`, `1d`, `7d`, `30d`, `60d`, `90d`, `180d`, `1y` (365 days), or `never` lifetime; `never` is the default and remains revocable. Legacy numeric `30`, `60`, and `90` values remain accepted. The plugin configuration does not contain a pasted token. These packages provide local stdio MCP servers only.
